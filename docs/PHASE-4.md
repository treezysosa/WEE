# Phase 4 — editing, presets and history (first increment)

EDIT / LIBRARY expands the selected layer's piano roll. Select a layer in CREATE first. Click empty space to add a note, drag to move, Shift-drag to resize, Alt-drag vertically to change velocity, right-click or Delete to delete. Escape cancels a drag. Grid choices are quarter, eighth and sixteenth notes. FIT NOTES adjusts the visible pitch range. Notes may be chromatic when edited intentionally. Edits commit once per gesture, are sorted, bounded to the loop, and rejected when locked, stale, invalid or beyond 2,048 notes per layer.

UNDO / REDO covers generation, layer regeneration, note edits and preset loading. History lives in the processor, so closing the editor does not clear it. Version 4 project state stores up to eight snapshots per direction, bounded to 2 MiB per direction. Snapshots contain notes, seed and all parameters, but no nested history or rendered A/B audio. New transactions discard redo. Oldest history is evicted when its limits are reached. Individual knob automation and mixer gestures do not create history transactions. Versions 1–3 still restore exact saved notes; old states receive a Balanced mood by default.

The library contains six original deterministic factory arrangements and local `.wee` files in Documents/WEE/Presets. LOAD applies the selected item; SAVE PRESET captures the current full arrangement and parameters before opening the save dialog. OPEN .wee loads presets elsewhere. Saves use a temporary file and replacement with overwrite confirmation. Invalid files leave current content intact. Loading creates an undo snapshot, including when replacing locked layers: a preset explicitly replaces the whole arrangement. Presets omit history. Host synchronization is disabled in factory presets to audition their intended tempos; enable Host sync to follow the DAW.

Balanced, Reflective and Energetic phrasing affect lead/counter melody rests and velocities on the next GENERATE. Four-bar phrases include a response figure and cadence; generation remains seed-based and scale-aware. Changing mood alone does not rewrite existing MIDI. All layers share the progression; sustained backing parts retain their instrument-specific phrasing.

DRAG MIDI writes a real standard MIDI file under the user's application-data WEE/Drag Exports folder, keeping the source available after the editor closes. SAVE ALL MIDI remains the supported fallback. Drag files are retained; users may remove old files there when finished. WAV drag/export retains the Phase 3 implementation.

Automated verification adds actual processor editing, locks, invalid-input preservation, undo/redo, state reload with history, editor-close retention, preset restore/rejection and bounded-history tests. Portable suites also cover composition, all layer harmony contexts, MIDI and DSP/WAV. Windows compile and test results are recorded in VALIDATION.md after CI completes. FL Studio interactive tests still require the DAW.

This is a Phase 4 increment, not completion of every advanced-generation/editor idea. Remaining work includes zoom/scroll, multi-note selections, keyboard nudging, visual velocity lanes, preset search/tags, performance-oriented library browsing, richer phrase algorithms, and interactive FL Studio drag testing. No sample packs, accounts or inference service are required.
